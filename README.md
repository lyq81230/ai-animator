# Spine 动作生成器

把一套**分层的角色素材**丢进去，自动生成骨骼 + 蒙皮 + 动作动画，输出可直接导入 Spine 3.8 的 `result.json`。
生成动作不需要视频、不需要显卡、不需要联网（只有可选的 AI 自动拆图才要用 NVIDIA 显卡）。

## 它做什么

输入是拆好的部件图（头发、脸、眼、手臂三段……），输出是**骨骼动画**——骨关键帧 + 权重网格，
不是逐帧序列图。支持四种动作：

| 动作 | 类型 | 内容 |
|---|---|---|
| 待机 | 循环 | 呼吸起伏、2.5D 转头、风吹发丝、微摆臂、眨眼 |
| 行走 | 循环 | 重心起伏与左右移、躯干前倾反扭、摆臂、双腿交替迈步、发丝滞后（原地走，位移交给引擎） |
| 受击 | 一次性 | 瞬间后仰击退、衰减回弹、下盘卸力、末帧归位可直接接回待机 |
| 死亡 | 一次性 | 卸力屈膝、加速塌倒、触地压扁、四肢瘫软、闭眼、化掉消失 |

导出格式：**Spine 3.8**（主），或 **DragonBones 5.5**（给 Cocos 用）。

## 设计上的一点区别

流程是**两步**的：拆图 → 做动作。

拆图把素材切成部件、算好坐标，产物存在 `output/<素材名>/parts/`；之后生成动作只读这份产物。
平面图的 AI 拆图一张要 2~4 分钟，拆一次之后待机 / 行走 / 受击 / 死亡都能反复生成、随便调参数重出，
不用重复等待。

界面和命令行是同一套代码：GUI 只是把参数拼成命令行去调 `build_from_seethrough.py` 和
`gen_idle_bones.py`，所以批量出图可以直接调脚本，不用开界面。

## 安装

不用装任何东西，包里自带便携版 Python 和依赖。解压到任意目录（路径别太深），双击 **`run.bat`** 即可。

想用系统 Python 也可以：删掉 `python\` 目录，`run.bat` 会改用系统 Python 3.9+ 并自动
`pip install -r requirements.txt`（PySide6 / numpy / Pillow / opencv-python / psd-tools）。

## 用法

1. 双击 `run.bat`，把素材拖进左上角虚线框
2. 点 **① 拆图**，看右侧「拆图体检单」确认部件都拆对了
3. 在「② 动作」勾选要的动作（可多选），调幅度 / 速度
4. 点生成，产物在 `output/<素材名>/` 下

拆图状态会显示成 `已拆图 · 22 部件 · 可做动作`；没拆图时生成按钮是灰的，避免拿半成品出动画。

## 输出

```
output/<素材名>/
  parts/                 ① 拆图：部件 PNG + coords.json
  _split_preview.png     ① 拆图：体检单
  idle/ walk/ hit/ death/   ② 动作：result.json + images/ + 预览 gif
  dragonbones/           可选：DragonBones 整套（一个骨架，多条动画）
```

每个动作默认时长：待机 5s / 行走 2s / 受击 0.9s / 死亡 2s。

## 可选：AI 自动拆图

手里只有一张平面图时，程序可以调模型自动分层（分出 24 个部位，手臂再切成大臂-小臂-手三段，
腿拆成左右两条）。这部分**不随包附带**，第一次用点界面上的「安装 AI 拆图组件」自动下载。

- 要求 NVIDIA 显卡、显存 6GB 以上（实测峰值 4.6GB），拆一张约 2~4 分钟
- 已经有分好层的素材（PSD / 带名字的 PNG）就不需要它
